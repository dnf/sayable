# Locale Code Generator

The `codegen/` directory contains a code generator that maintains all 49 locale definitions across the 8 language implementations from a single canonical source.

## Why

49 locales across 8 languages means 392 locale files. Before this generator, every locale change required editing up to 8 files by hand. The generator eliminates that by deriving all locale source files from one set of JSON definitions.

## Architecture

```
codegen/
  locales/           # 49 JSON files — the single source of truth
    en.json
    fr.json
    ar.json
    ...
  generate.py        # Orchestrator: loads JSON, runs emitters, writes files
  extract.py         # One-time bootstrap: read TS files → JSON (already run)
  plural_rules.py    # 12 plural rule patterns with per-language code emission
  emitters/          # One module per target language
    typescript.py
    python.py
    go.py
    ruby.py
    rust.py
    kotlin.py
    cpp.py
    php.py
```

## Canonical JSON format

One file per locale. Example (`fr.json`):

```json
{
  "code": "fr",
  "name": "French",
  "pluralRule": "one_other_zero_one",
  "units": {
    "day":   { "one": "{n} jour", "other": "{n} jours" },
    "week":  { "one": "{n} semaine", "other": "{n} semaines" },
    "month": "{n} mois",
    "year":  { "one": "{n} an", "other": "{n} ans" }
  },
  "half": "{0} et demi",
  "delimiter": ", ",
  "justBorn": "Nouveau-né",
  "stages": {
    "newborn": { "m": "Nouveau-né", "f": "Nouveau-née" },
    "infant": "Nourrisson",
    "toddler": "Tout-petit",
    "child": "Enfant",
    "teenager": { "m": "Adolescent", "f": "Adolescente" },
    "adult": "Adulte"
  }
}
```

### Field rules

- **`units`**: A string value means no plural forms (e.g. `"{n} mois"` for French months). An object maps plural categories to templates (`"other"` is required, rest optional).
- **`stages`**: A string means gender-neutral. An `{"m": ..., "f": ...}` object means gendered.
- **`pluralRule`**: One of the 12 named rules below. The rule's logic lives in `plural_rules.py`, not in the JSON.
- **`short`** / **`compact`**: Optional compactness overrides (same structure as `units`). Currently only English uses these.

## 12 plural rules

| Rule | Pattern | Locales |
|------|---------|---------|
| `other_only` | always `other` | ja, ko, zh, th, vi, ms, jv, hu, eu, ga |
| `one_other` | n=1 &rarr; `one` | en, bg, et, el, fi, sv, it, nb, nl, da, de, es, ca, sq, ta, te, tr, mr, ur |
| `one_other_zero_one` | n&isin;{0,1} &rarr; `one` | fr, pt, hi, fa, bn, gu, pa |
| `cs_sk` | 1=one; 2-4=few; else other | cs, sk |
| `lt` | mod10-based one/few/other | lt |
| `ro` | 1=one; 0 or mod100 1-19=few | ro |
| `slavic_bcs` | mod10 one/few/other | hr, bs, sr |
| `pl` | one/few/many | pl |
| `ru_uk` | mod10 one/few/many | ru, uk |
| `sl` | mod100 one/two/few/other | sl |
| `ar` | all 6 categories | ar |
| `lv` | zero/one/other | lv |

Each rule is defined once in `plural_rules.py` with code strings for all 8 target languages.

## Output per language

| Language | Output files | Pattern |
|----------|-------------|---------|
| TypeScript | `locales/{code}.ts` + `locales/index.ts` | one per locale + barrel |
| Python | `locales/{code}.py` + `locales/__init__.py` | one per locale + barrel |
| Go | `locale_{code}.go` | one per locale |
| Ruby | `locales/{code}.rb` | one per locale |
| Rust | `locales/{code}.rs` + `locales/mod.rs` | one per locale + barrel |
| Kotlin | `Locales.kt` | single file, all 49 |
| C++ | `locales_{a_e,f_k,l_r,s_z}.cpp` + `locales.hpp` | 4 files by alpha range + header |
| PHP | `Locales.php` | single file, all 49 |

Every generated file begins with a comment: `// This file is auto-generated by codegen/generate.py — do not edit manually.`

## Usage

### Generate all locale files

```bash
python -m codegen.generate
```

### Generate for one language only

```bash
python -m codegen.generate --lang typescript
python -m codegen.generate --lang python
python -m codegen.generate --lang go
# etc.
```

### Check for drift (CI mode)

```bash
python -m codegen.generate --check
```

Exits with code 1 if any generated file would change. This runs in CI to ensure locale files stay in sync with the canonical JSON.

## Workflows

### Modifying an existing locale

1. Edit the JSON file in `codegen/locales/{code}.json`
2. Run `python -m codegen.generate`
3. Run the test suites to verify

### Adding a new locale

1. Create `codegen/locales/{code}.json` with the locale data
2. Add the locale's plural rule to `plural_rules.py` (or use an existing rule)
3. Run `python -m codegen.generate`
4. Add test cases to `docs/testing.md` and implement them in all 8 test files
5. Run all test suites

### Fixing a plural rule

1. Edit the rule in `plural_rules.py` (it has per-language code strings)
2. Run `python -m codegen.generate`
3. Run all test suites

## How it was bootstrapped

The `extract.py` script was a one-time tool that read the 49 TypeScript locale files (the reference implementation) and produced the canonical JSON files. It does not need to be run again — the JSON files are now the source of truth, and the TypeScript files are generated from them.

## Requirements

Python 3.10+ (stdlib only, no dependencies).
