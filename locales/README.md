# Sayable Locale Index

Quick reference for linguists: find and edit the JSON locale file for any language across all Sayable libraries.

Each locale is defined in a single JSON file per library. Edit the JSON, then run the library's codegen to regenerate source files in all programming languages.

## How to edit

1. Click a link below to open the locale JSON file
2. Edit the translations directly in the JSON
3. Regenerate:
   - **age:** `cd age && python -m codegen.generate`
   - **date:** `cd date && python -m codegen.generate`
   - **duration:** `cd duration && python -m codegen.generate`
   - **time:** `cd time && python -m codegen.generate`
