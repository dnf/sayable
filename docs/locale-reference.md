## Plural rules

There are 23 distinct plural rule patterns used across the 71 locales,
covering all CLDR cardinal plural patterns:

| Rule                 | Categories                       | Logic                                                                                  | Used by                                                                                                |
| -------------------- | -------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `ar`                 | zero, one, two, few, many, other | Full Arabic CLDR pattern                                                               | ar                                                                                                     |
| `br`                 | one, two, few, many, other       | Breton mod-10/mod-100 pattern                                                          | br                                                                                                     |
| `cs_sk`              | one, few, other                  | n=1 &rarr; one, n&isin;2..4 &rarr; few                                                 | cs, sk                                                                                                 |
| `cy`                 | zero, one, two, few, many, other | n=0 &rarr; zero, n=1 &rarr; one, n=2 &rarr; two, n=3 &rarr; few, n=6 &rarr; many       | cy                                                                                                     |
| `ga`                 | one, two, few, many, other       | n=1 &rarr; one, n=2 &rarr; two, n&isin;3..6 &rarr; few, n&isin;7..10 &rarr; many       | ga                                                                                                     |
| `gd`                 | one, two, few, other             | n&isin;{1,11} &rarr; one, n&isin;{2,12} &rarr; two, n&isin;3..10&cup;13..19 &rarr; few | gd                                                                                                     |
| `gv`                 | one, two, few, other             | n%10=1 &rarr; one, n%10=2 &rarr; two, n%100&isin;{0,20,40,60,80} &rarr; few            | gv                                                                                                     |
| `he`                 | one, two, other                  | n=1 &rarr; one, n=2 &rarr; two                                                         | he                                                                                                     |
| `kw`                 | zero, one, two, few, many, other | Cornish mod-100 pattern                                                                | kw                                                                                                     |
| `lt`                 | one, few, other                  | Lithuanian mod-10/mod-100                                                              | lt                                                                                                     |
| `lv`                 | zero, one, other                 | Latvian mod-10/mod-100                                                                 | lv                                                                                                     |
| `mk`                 | one, other                       | n%10=1 and n%100&ne;11 &rarr; one                                                      | mk                                                                                                     |
| `mt`                 | one, two, few, many, other       | n=1 &rarr; one, n=2 &rarr; two, Maltese broken-plural pattern                          | mt                                                                                                     |
| `one_other`          | one, other                       | n=1 &rarr; one                                                                         | az, bg, ca, da, de, el, en, es, et, fi, it, ka, kk, mr, nb, ne, nl, sq, sv, sw, ta, te, tr, uk, ur, uz |

| `ru_uk`              | one, few, many                   | Slavic mod-10/mod-100 with many                                                        | ru, uk                                                                                                 |
| `shi`                | one, few, other                  | n&isin;{0,1} &rarr; one, n&isin;2..10 &rarr; few                                       | shi                                                                                                    |
